# ScreenshotShelf updates

Public distribution of ScreenshotShelf for macOS. Application source code is private.

- [Update feed](https://miguelrrl.github.io/ScreenshotShelf-updates/appcast.xml)
- [Download 0.7.8](https://miguelrrl.github.io/ScreenshotShelf-updates/ScreenshotShelf-0.7.8.dmg)

Install 0.7.8 manually once if using 0.7.7 or earlier. Later versions can use Check for Updates.

Installers use Sparkle EdDSA signatures. This repository contains only installers, release notes, and the update feed.
